# Reverse 3D

Input: a finished video (max 18 seconds).

Output: a blocky Blender-viewport playblast restyle via Kling 4.0 Edit. The side-by-side compare (playblast left, original right) is built in the browser so the graph does not OOM stitching frames.

This workflow is playblast-only: LoadVideo → Kling4EditVideoNode → SaveVideo.
